## 技术实现细节

### Reconciliation 逻辑

```python
async def _reconcile_if_needed(db, thread_id, checkpoint_tuple):
    # 1. 提取 checkpoint_id
    checkpoint_id = checkpoint_tuple.config.get("configurable", {}).get("checkpoint_id")
    
    # 2. 检查 PG 状态
    status = await ProjectionService.get_projection_status(db, thread_id)
    
    # 3. 如果不一致，投影
    if not status.get("exists") or status.get("latest_checkpoint_id") != checkpoint_id:
        await ProjectionService.project_from_checkpoint(db, thread_id, checkpoint_tuple)
```

### PG-first 搜索优势

**旧架构（Store-first）**:
- 扫描所有 Store 记录（O(all_threads)）
- 然后逐个检查 ownership

**新架构（PG-first）**:
- 直接查询 `WHERE owner_user_id = ?`（O(user_threads)）
- 利用数据库索引，性能提升显著
- 仅在 DB 不可用时才回退到 Store

### 读前一致性保证

所有读取端点在返回数据前执行 targeted reconciliation：

```python
# get_thread / get_thread_state / get_thread_history
checkpoint_tuple = await checkpointer.aget_tuple(config)
if db is not None:
    await _reconcile_if_needed(db, thread_id, checkpoint_tuple)
# 现在可以安全地从 PG 读取或返回 checkpoint 数据
```
