## 技术实现细节

### Projection Service 架构

```python
# 统一投影入口
ProjectionService.project_from_stream_event(
    db=db,
    thread_id=thread_id,
    event="values",
    data=event_data,
    checkpoint_id="checkpoint-123",
)

# 返回结果
{
    "projected": True,
    "message_count": 5,
    "checkpoint_id": "checkpoint-123",
    "synced_at": "2026-04-06T10:00:00Z"
}
```

### 锚点字段更新逻辑

```python
# 原子更新 chat 锚点
chat.latest_checkpoint_id = checkpoint_id
chat.latest_checkpoint_at = now
chat.projection_synced_at = now
await db.commit()
```

### 滞后检测

```python
# 计算投影滞后
lag_seconds = (projection_synced_at - latest_checkpoint_at).total_seconds()

# 索引支持高效查询
CREATE INDEX ix_chats_projection_lag 
ON chats (latest_checkpoint_at, projection_synced_at)
```
