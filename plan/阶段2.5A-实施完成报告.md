## 技术实现细节

### Checkpointer 工厂模式
```python
# backend/packages/harness/deerflow/agents/checkpointer/async_provider.py
async with make_checkpointer() as checkpointer:
    # 根据 config.yaml 中的 checkpointer.type 自动选择后端
    # - memory: InMemorySaver
    # - sqlite: AsyncSqliteSaver
    # - postgres: AsyncPostgresSaver
```

### Store 工厂模式
```python
# backend/packages/harness/deerflow/runtime/store/async_provider.py
async with make_store() as store:
    # 自动跟随 checkpointer 配置使用相同后端
```

### 配置优先级
1. `DEER_FLOW_CHECKPOINTER_DATABASE_URL` 环境变量
2. `config.yaml` 中的 `checkpointer.connection_string`

## 回滚准备
如需回滚到 SQLite 模式，只需修改 `config.yaml`：
```yaml
checkpointer:
  type: sqlite
  connection_string: checkpoints.db
```
